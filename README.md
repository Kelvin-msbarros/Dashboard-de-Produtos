# 📊 Dashboard de Análise de Produtos | SQL + Power BI

Projeto de Business Intelligence desenvolvido com o objetivo de transformar dados armazenados em uma base SQL em informações gerenciais para análise de produtos e apoio à tomada de decisão.

A solução contempla a consulta, organização e preparação dos dados no banco SQL e a construção de um dashboard interativo no Power BI.

## 🎯 Objetivo

O objetivo do projeto foi desenvolver uma solução de Business Intelligence para análise de dados de produtos, utilizando SQL como camada de consulta e preparação dos dados e Power BI para modelagem, criação de indicadores e visualização.

A arquitetura utilizada foi:

Base de Dados SQL → Consultas SQL → Power BI → Dashboard

A proposta foi concentrar o tratamento e organização dos dados o mais próximo possível da fonte, disponibilizando para o Power BI informações estruturadas para análise.

## 🗄️ SQL

O SQL foi utilizado para consultar e preparar os dados utilizados pelo dashboard.

Durante o desenvolvimento foram trabalhados conceitos como:

- Consultas SELECT;
- Filtros e condições;
- Agregações;
- GROUP BY;
- JOIN entre tabelas;
- Tratamento e organização dos dados;
- Validação dos resultados;
- Preparação dos dados para consumo analítico.

A utilização do SQL permitiu disponibilizar ao Power BI uma base mais estruturada e adequada para construção dos indicadores.

---

## 📈 Power BI

Após a preparação dos dados no SQL, as informações foram consumidas no Power BI para construção do dashboard.

O projeto foi desenvolvido buscando:

- Visualização clara dos principais indicadores;
- Análise do desempenho dos produtos;
- Comparação entre diferentes categorias e períodos;
- Identificação de produtos com maior representatividade;
- Acompanhamento de tendências;
- Utilização de filtros para exploração dos dados;
- Facilidade de interpretação das informações pelo usuário.

---

## 🧮 Indicadores

O dashboard permite analisar diferentes aspectos relacionados ao desempenho dos produtos.

Os indicadores foram desenvolvidos utilizando os dados provenientes do banco SQL e medidas criadas no Power BI com DAX.

A combinação entre SQL e Power BI permite que o usuário explore os resultados em diferentes níveis de detalhe e identifique padrões relevantes nos dados.

## 💡 Principais decisões técnicas

Durante o desenvolvimento, algumas decisões foram adotadas para manter a solução organizada e facilitar sua manutenção:

- Utilização do SQL para consulta e preparação dos dados;
- Separação entre camada de dados e camada de visualização;
- Validação dos resultados antes da construção dos indicadores;
- Utilização de DAX para criação das métricas analíticas;
- Desenvolvimento de uma interface simples e orientada à análise;
- Utilização de filtros para permitir diferentes recortes das informações.
